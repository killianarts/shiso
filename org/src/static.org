#+title: Static Files
#+property: header-args:common-lisp


Shiso's static file serving layer, inspired by Django's staticfiles app.

Static files are served under a single =/static/= URL prefix using a two-tier
lookup strategy:

- *Project-wide*: The project's =static/= directory holds global assets (CSS,
  JS, images) and, in production, collected module assets.
- *Per-module*: Each module can have its own =static/= directory alongside its
  source files. In development, the middleware searches these directories
  directly. In production, =collectstatic= copies them into the project's
  =static/<module-name>/= directory so everything is served from one place.

=cached-static= optionally returns content-hashed URLs (production manifest)
or mtime query strings (development) so browsers do not keep stale CSS/JS.

* Package Definition

The =shiso/static= package depends on =shiso/modules= for the module class and
registry. The load order =modules= → =static= → =routing= avoids any circular
dependency. =ironclad= provides SHA-256 for content fingerprints.

(defpackage #:shiso/static

(in-package #:shiso/static)
#+end_src

See =src/static.lisp= for the full implementation: content hashing,
=staticfiles.json= manifest I/O, =collectstatic :hash t=, =cached-static=,
and middleware resolution of hashed filenames.

* Module Static Roots

Build an alist mapping module names to their source =static/= directories by
traversing the module registry. This is called once at application construction
time (inside =define-application=) and passed to the middleware.

* File Lookup

Given a relative path (already stripped of the =/static/= prefix), search:

1. *Project root*: =static/<relative-path>=
2. *Module roots*: first path segment as module name
3. *Hashed fallback*: if the basename looks like =stem.<8–12 hex>.ext=, strip
   the hex segment and retry (dev middleware serving manifest URLs)

* collectstatic

Copy every registered module's =static/= into =TARGET/<module-name>/=.
With =:hash t=, also write =stem.<hash>.ext= siblings and
=TARGET/staticfiles.json=. Unhashed names remain; old hashes accumulate.

* cached-static

Opt-in URL helper. Manifest hit → hashed path; no manifest → =?v=<mtime>=;
unknown path → unversioned =/static/…= with a one-time warning.
