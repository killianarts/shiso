#+title: Shiso
#+author: Micah Killian

A web framework for Common Lisp. Django-shaped: modular apps,
ORM-backed models, an auto-generated admin, session+CSRF auth, and
a scaffolder that stamps both.

* Quickstart

#+begin_src bash
# Install the framework
git clone <shiso-repo-url>
cd shiso
make && make install

# Scaffold + run a project
shiso new-application hello
cd hello
vend get
make
./hello                              # listening on http://127.0.0.1:5000
#+end_src

For a full walk-through see [[file:docs/tutorial/01-getting-started.org][docs/tutorial/01-getting-started]].

Two complete apps live under [[file:examples/][examples/]] and are

* Requirements

- [[http://www.sbcl.org/][SBCL]] 2.x or later, on =$PATH=.
- [[https://github.com/fosskers/vend][vend]] for vendoring dependencies
  into your applications. Installed the same way as Shiso: clone,
  =make=, =make install=.
- GNU Make.

* Installing

#+begin_src bash
git clone <shiso-repo-url>
cd shiso
make
make install
#+end_src

After =make install= you'll have:

- =$(PREFIX)/bin/shiso= — the scaffolder binary (default prefix
  =~/.local=, override with =make install PREFIX=/usr/local=).
- =$(ASDF_DIR)/shiso/= — a full copy of the Shiso source tree (default
  =~/common-lisp/shiso/=). This is where the binary reads its skeleton
  templates from at runtime, and it's also discoverable by ASDF for
  REPL use.

The original clone is disposable after =make install=. Re-running
=make install= from any Shiso checkout overwrites the installed
copy, which is how you propagate local template customizations
system-wide.

** Uninstalling

#+begin_src bash
make uninstall
#+end_src

Removes both the binary and =~/common-lisp/shiso/=.

** Overrides

| Variable   | Default               | Purpose                               |
|------------+-----------------------+---------------------------------------|
| =LISP=     | =sbcl=                | Lisp implementation used to build     |
| =PREFIX=   | =$(HOME)/.local=      | Where the =shiso= binary is installed |
| =ASDF_DIR= | =$(HOME)/common-lisp= | Where the source tree is copied       |

Example: =make install PREFIX=/usr/local ASDF_DIR=/opt=

* Using the scaffolder

The =shiso= binary has two commands. Detailed coverage of both
(plus the layout of the trees they stamp) lives in
[[file:docs/tutorial/01-getting-started.org][docs/tutorial/01-getting-started]].

** =shiso new-application <name>=

Scaffold a fresh project in =./<name>/= — =.asd=, =Makefile=,
=src/main.lisp=, =src/routes.lisp=, etc.

** =shiso new-module <name>=

Scaffold a module under =src/modules/<name>/= in the current
project. The scaffolder prints the manual wiring lines you need
(adding =:<name>= to =:depends-on= and the mount to your
application's =define-application=) but deliberately does not edit
those files for you.

* Customising the scaffolder templates

The templates live under =$SHISO_HOME/skeleton/= (defaults to
=~/common-lisp/shiso/skeleton/=). Substitution syntax is cl-emb's
=@var= directive (e.g. =<%@var name%>=). Full instructions in the
[[file:docs/how-to/customize-the-scaffolder-templates.org][how-to guide]].
