#+TITLE: Shiso documentation
#+OPTIONS: toc:2 num:nil

Shiso is a Django-shaped web framework for Common Lisp: modular apps,
ORM-backed models, an auto-generated admin, session+CSRF auth, and a
scaffolder that stamps both.

This documentation follows the [[https://diataxis.fr/][Diátaxis]] model. It splits into four
quadrants — pick the one that matches what you're trying to do right
now.

* Working examples

The =examples/= directory at the repository root contains two real,
runnable Shiso apps that the tutorials walk through:

- =examples/mysite/= — the Django-poll-style polls site
  (Question / Choice / vote flow / admin).
- =examples/todo/= — the TODO walkthrough (single resource, CRUD,
  CSRF-protected forms, optional auth).

Both can be loaded straight from a REPL or built into a binary with
=make=. The tutorials cross-reference these files line by line.

* Heads-up: the almighty-html =</> = DSL

A handful of the gotchas in this documentation come from how the
=almighty-html= HTML DSL (=</>=) macro walks its body. Three things
to internalise early — every tutorial reminds you of these in
context, but flagging them here too:

1. =</>= looks up element names by /symbol name only/, ignoring the
   symbol's package. =(models:title todo)= inside =</>= is parsed as
   the HTML =<title>= element, not as a function call. Bind the
   value to a local first: =(let ((todo-title (models:title todo)))
   (ah:</> (span todo-title)))=.
2. =</>= walks its body looking for component calls (symbol names
   starting with =ac-=). Two-character symbols like =IF= crash the
   detector, so don't write =(if …)= directly inside =</>=. Use
   =when=, =unless=, =cond=, or compute the conditional value in a
   surrounding =let= and reference it.
3. =</>= passes its body straight through to the underlying element
   function — =(loop …)= inside it evaluates normally, but the
   compiler can't always track variable use through the macro
   walker; if you see a spurious "variable X is defined but never
   used" style warning that escalates to a compile-file failure,
   move that piece out into a helper function.
