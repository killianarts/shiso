#+TITLE: Reference: cli
#+OPTIONS: toc:2 num:nil

The =shiso= binary is built from the =shiso= system itself
(=:build-pathname "shiso"=, =:entry-point "shiso/cli:main"=). After
=make install= it lives at =$(PREFIX)/bin/shiso= (default
=~/.local/bin/shiso=).

* Commands

#+begin_src bash
shiso new-application <name>
shiso new-module <name>
shiso --help
shiso --version
#+end_src

=--help= and =--version= are provided automatically by clingon, the
argument parser the CLI is built on. =shiso new-application --help= and
=shiso new-module --help= print the per-subcommand usage.

** =new-application <name>=

Stamps =skeleton/app/= into =./<name>/=. Refuses to overwrite an
existing directory. Substitutes =<%@var application-name%>= with
=<name>=. Prints next-step instructions.

#+begin_example
shiso new-application hello
# Creates ./hello/, then prints:
#   cd hello
#   vend get
#   make
#   ./hello
#+end_example

** =new-module <name>=

Stamps =skeleton/module/= into =./src/modules/<name>/=. Refuses to
overwrite. Substitutes =<%@var module-name%>= with =<name>=. Prints
the manual wiring lines you need to add to your app's =.asd= and
=src/routes.lisp= (the scaffolder deliberately doesn't edit those
for you).

* =SHISO_HOME= environment variable

Tells the binary where to find the skeleton templates. Defaults to
=~/common-lisp/shiso/= — the install location. Set it to a working
checkout when iterating on the templates:

#+begin_src bash
export SHISO_HOME=~/code/shiso
shiso new-application demo
#+end_src

See [[../how-to/customize-the-scaffolder-templates.org][how-to: customize the scaffolder templates]].

* Template substitution

The renderer is in =src/cli/render.lisp=. The substitution syntax is
cl-emb's =@var= directive:

#+begin_example
<% @var application-name %>
<%@var module-name%>
<%@var KEY%>
#+end_example

…all match. Both file paths and file contents go through the same
substitution.

The bindings alist is built in =src/cli/commands.lisp=:

| Command            | Binding key         | Value        |
|--------------------+---------------------+--------------|
| =new-application=  | =application-name=  | CLI =<name>= |
| =new-module=       | =module-name=       | CLI =<name>= |

To add more, declare extra options on the relevant
=clingon:make-command= form in =src/cli/main.lisp= (read them with
=clingon:getopt= inside the handler) and thread the values through to
=commands.lisp=.

* Exit codes

| Code | Meaning                                                  |
|------+----------------------------------------------------------|
| 0    | Success                                                  |
| 1    | Missing argument, unknown command, or target already exists |

The binary doesn't log to a file; everything goes to stdout/stderr.
