#+TITLE: Reference: forms
#+OPTIONS: toc:2 num:nil

Package: =shiso/forms=. Form objects bind a set of fields to a
chunk of submitted data, validate it, and (for model forms) persist
it.

* Field classes

All inherit from =form-field=.

| Class             | Used for                                |
|-------------------+-----------------------------------------|
| =form-field=      | Base; you rarely instantiate it directly |
| =char-field=      | =<input type=text>= with optional =max-length= |
| =text-field=      | =<textarea>=                            |
| =integer-field=   | =<input type=number>=                   |
| =boolean-field=   | =<input type=checkbox>=                 |
| =choice-field=    | =<select>= with options from =:choices= |
| =email-field=     | =<input type=email>=                    |
| =date-field=      | =<input type=datetime-local>=           |

** Common initargs

| =:name=       | symbol — used as the form field name             |
| =:label=      | string — English fallback; translated at render  |
| =:label-id=   | optional Fluent id; model forms set this         |
| =:help-text=  | string or =NIL=                                  |
| =:help-id=    | optional Fluent id for help text                 |
| =:requiredp=  | =T= (default) — empty values are rejected        |
| =:validators= | list of validator designators                    |
| =:initial=    | initial value, shown when no submitted data      |
| =:widget=     | optional widget keyword override                 |

** Field-specific initargs

| =char-field=   | =:max-length= integer or =NIL=  |
| =choice-field= | =:choices= alist of =(KEY . LABEL)= |

** Accessors

For each initarg there's a same-named reader: =field-name=,
=field-label=, =field-label-id=, =field-help-text=, =field-help-id=,
=field-requiredp=, =field-validators=, =field-initial=,
=field-widget=, =field-max-length=, =field-choices=.

=make-model-form= sets =:label-id= to =(message-id MODEL FIELD)=
and =:help-id= when help text is present. =render-field= translates
those ids at render time; see [[file:i18n.org][i18n]].

* =parse-field-value=  /generic function/

#+begin_src lisp
(parse-field-value FIELD RAW-VALUE) => parsed-value
#+end_src

Convert a raw string from the request body into the right Lisp
type. Specialised methods:

| Field            | Conversion                                          |
|------------------+-----------------------------------------------------|
| =form-field=     | Identity                                            |
| =integer-field=  | =parse-integer= with =:junk-allowed t=              |
| =boolean-field=  | =T= if present and non-empty, =NIL= otherwise (HTML checkboxes) |
| =choice-field=   | Interns to keyword if =:choices= are keyword-keyed  |
| =date-field=     | =local-time:parse-timestring= (with seconds appended) |

* =form=  /class/

The base form. Slots:

| Slot           | Reader/Accessor       | Initarg         |
|----------------+-----------------------+-----------------|
| =fields=       | =form-fields=         | =:fields=       |
| =data=         | =form-data=           | =:data=         |
| =instance=     | =form-instance=       | =:instance=     |
| =errors=       | =form-errors=         | (populated by =validate-form=) |
| =cleaned-data= | =form-cleaned-data=   | (populated by =validate-form=) |

- =fields= — a list of field instances.
- =data= — alist of =(STRING-NAME . STRING-VALUE)= as submitted.
- =instance= — the underlying Mito instance, for edit forms.
- =errors= — hash table keyed by field name symbol (or =:__all__=
  for cross-field errors) → list of error strings.
- =cleaned-data= — hash table keyed by field name symbol → parsed
  value.

* =validate-form=  /generic function/

#+begin_src lisp
(validate-form FORM) => t-or-nil
#+end_src

Run all per-field validators (auto-derived ones plus those declared
on the field), populate =cleaned-data= and =errors=, then call
=clean= for cross-field validation.

Returns =T= if no errors landed.

** Auto-validators

For each field, =validate-form= runs these /in addition to/
explicit field validators:

- =not-blank= if =requiredp= and =not-blank= isn't already listed.
- =one-of= for =choice-field=, restricted to its declared keys.
- =max-length= for =char-field= with a non-nil =max-length=.

The auto-validators don't duplicate explicit ones — the form's
=has-validator-p= helper de-dups by car-symbol.

* =clean=  /generic function/

#+begin_src lisp
(clean FORM CLEANED-DATA) => list-of-error-strings-or-nil
#+end_src

Cross-field validation hook. Override with a defmethod on your
form subclass. =CLEANED-DATA= is the hash table from successful
per-field parses.

The shipped =:before= behaviour is no-op. The auth signup form's
=clean= is a working reference — see =src/auth/forms.lisp=.

* =form-validp=  /function/

#+begin_src lisp
(form-validp FORM) => boolean
#+end_src

True iff =errors= is empty. Call after =validate-form=.

* Model forms

** =model-form=  /class/

A =form= subclass with one extra slot:

| Slot         | Reader/Accessor          | Initarg     |
|--------------+--------------------------+-------------|
| =model-name= | =model-form-model-name=  | =:model-name= |

** =make-model-form=  /function/

#+begin_src lisp
(shiso/forms:make-model-form MODEL-NAME &key fields exclude instance data)
  => model-form
#+end_src

Build a form whose fields are derived from a model's registered
slot metadata.

| Key         | Effect                                              |
|-------------+-----------------------------------------------------|
| =:fields=   | If non-nil, include only these slot names           |
| =:exclude=  | Slot names to exclude                               |
| =:instance= | Edit form: initial values come from the instance    |
| =:data=     | Submitted data alist                                |

The conversion from slot metadata to form fields:

- =:varchar= columns → =char-field= with =max-length=.
- =:text= → =text-field=.
- =:integer= → =integer-field=.
- =:boolean= → =boolean-field=.
- =:timestamp= / =:timestamptz= / =:date= → =date-field=.
- Slots with =:choices= → =choice-field= regardless of col-type.

Slots with =:editablep nil= are dropped.

** =save-form=  /function/

#+begin_src lisp
(shiso/forms:save-form MODEL-FORM) => persisted-dao
#+end_src

Persist a validated model form. If =form-instance= is non-nil, the
function updates its slots from =cleaned-data= and calls
=mito:save-dao=. Otherwise it calls =mito:create-dao= with the
cleaned data turned into a keyword-arg plist.

Don't call =save-form= on a form whose =validate-form= returned
=NIL= — the cleaned data is incomplete.

* Headless context

The form object owns validation, coercion, sticky values, and errors.
Markup is optional — pull state with =field-context= and render
whatever HTML you want.

** =field-context=  /function/

#+begin_src lisp
(field-context FORM FIELD-DESIGNATOR) => plist
#+end_src

=FIELD-DESIGNATOR= is a form-field object or a symbol/string naming
one. Returns a plist:

| Key            | Meaning                                          |
|----------------+--------------------------------------------------|
| =:name=        | slot-name symbol                                 |
| =:name-string= | downcased name for =name=/id= attributes         |
| =:label=       | human label                                      |
| =:help-text=   | help text or =NIL=                               |
| =:value=       | sticky value (submitted data, else initial)      |
| =:errors=      | list of error strings, or =NIL=                  |
| =:requiredp=   | =T= when the field must not be blank             |
| =:widget=      | concrete widget keyword (see =resolve-widget=)   |
| =:choices=     | choice alist, or =NIL=                           |
| =:max-length=  | varchar limit for char fields, or =NIL=          |

Scaffolded apps stamp =ac-field= / =ac-fields= /
=ac-csrf-input= into =src/hypermedia/form-components.lisp=. Those
components consume =field-context= plists; edit them to restyle the
whole app.

** =resolve-widget=  /function/

#+begin_src lisp
(resolve-widget FIELD) => widget-keyword
#+end_src

Explicit =:widget= from model metadata wins; otherwise a default is
derived from the field class (=text-field= → =:textarea=,
=boolean-field= → =:checkbox=, …).

** =request-form-data=  /function/

#+begin_src lisp
(request-form-data) => alist of (downcased-string . value)
#+end_src

Canonical body parameters for a form's =:data=. Prefer this over
=parse-body-params= when building forms — field lookup is by
string-equal name, and string keys avoid package surprises.

** =cleaned-value=  /function/

#+begin_src lisp
(cleaned-value FORM NAME) => value-or-nil
#+end_src

Read a cleaned field after =validate-form=, matching =NAME= by
symbol name string (so callers in other packages still hit).

** =register-widget-field-class=  /function/

#+begin_src lisp
(register-widget-field-class WIDGET CLASS-NAME)
#+end_src

Map a widget keyword to a form-field class consulted during
=make-model-form= generation (before col-type mapping). Built-in:
=:email= → =email-field=. Pair a custom =define-field-type= that
sets =:widget= with a registration here (and a =parse-field-value=
method when coercion differs).

* Rendering

Rendering is style-dispatched so apps can specialise without
clobbering the admin.

** =render-field=  /generic function/

#+begin_src lisp
(render-field STYLE FIELD &key value errors) => almighty-html-element
#+end_src

Dispatches on =STYLE= (first) then =FIELD=. The default method
(=(STYLE t)=) honours the field's resolved widget. The admin always
passes =:style :admin=, so app EQL methods on other keywords never
affect admin pages.

The default rendering produces:

#+begin_example
<div class="form-group" id="form-row-<name>">
  <label for="…">…</label>
  <input … />
  <p class="help-text">…</p>
  <ul class="field-errors"><li>…</li>…</ul>
</div>
#+end_example

Hidden widgets emit only the input. Checkboxes wrap the control
inside the label. No external CSS is included — the admin module
ships inline styles for these classes; your own pages need to either
re-use those or write your own.

** =render-fields=  /function/

#+begin_src lisp
(render-fields FORM &key (style t)) => list-of-elements
#+end_src

Render each of =FORM='s fields via =render-field=. Emits no
=<form>= wrapper — compose the result inside your own form tag
alongside a CSRF input and submit button.

** =render-form=  /function/

#+begin_src lisp
(render-form FORM &key (action "") (method "POST")
                      (submit-label "Submit") (style t))
  => almighty-html-element
#+end_src

Whole-form sugar: =render-fields= plus submit button inside a
=<form>=. Non-GET methods get a hidden =_csrf_token= input
prepended automatically (via =shiso:csrf-token-value=).

Use =render-form= for prototypes and admin-style pages. For
designed app pages, prefer =field-context= + scaffolded
=ac-field= / =ac-fields= so markup lives in your tree.
